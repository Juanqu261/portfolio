# ExploreAntioquia
## Description
ExploreAntioquia is an application designed to deliver personalized, unique tourism experiences to travelers. The core idea is to use tourism data to suggest tailored itineraries, gastronomy recommendations, and activities based on each user's individual preferences.

## Usage
The app lives at: [ExploreAntioquia](https://github.com/juquinterope/ppi_dai_QUINTEROjf/tree/main/ExploreAntioquia)

## Scripts
The [scripts](https://github.com/juquinterope/ppi_dai_QUINTEROjf/tree/main/scripts) folder contains code used to clean and collect the data (csv, geojson, etc.) consumed by the app.

## Libraries Used
The functionality relies on several *Python* libraries:

contextily: builds base maps with coordinate systems.

django: framework used to build and manage the web application.

geopandas: essential for geographically representing points of interest and recommended routes. Lets us visualize touristic data clearly and concisely.

io: stream handling.

matplotlib: heatmap generation.

numpy: required for storing data as arrays when training ML models.

pandas: foundational for data management and analysis — handles large structured datasets efficiently.

python-decouple: loads environment variables.

requests: accesses the external APIs we consume.

scipy: natural-language analysis.

nltk: NLP utilities.

------------------------------------------------------------------------------------------------------------------------------------------------------------------

*JavaScript* libraries used:

leaflet: interactive, browser-optimized maps.
